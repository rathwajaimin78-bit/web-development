## 🎬 Project: Netflix-Inspired UI Clone

A practice project created with **HTML and CSS** to learn webpage layout and styling.

**What I practiced**
- Building a landing-page layout
- Positioning text and interface elements over a background
- Styling buttons and an email input field
- Using images and visual sections to recreate a streaming-service-inspired interface

**Important notes**
- This is an educational frontend exercise, not the official Netflix website.
- It is not affiliated with or endorsed by Netflix.
- The email input is a visual UI element only; the project is not intended to collect or transmit personal information.
- Do not enter real personal information into demo projects.

## ▶️ Run a Project Locally

1. Clone or download this repository.
2. Open the project folder you want to explore.
3. Open its HTML file in a browser, or use the **Live Server** extension in VS Code if you have it installed.
4. Read the HTML and CSS files to understand how the page is built.
